# 차량 모드 런처 (CarMode Launcher)

삼성 S20 (Android 13) 용 차량 홈 런처. 1차 버전.

## 들어있는 기능

- **홈 런처 등록** — 홈 버튼 누르면 이 앱이 뜨도록 설정됨
- **시계 + 날씨** — 실시간 시계, Open-Meteo 날씨 (키 불필요)
- **날씨 상세** — 체감/습도/바람/강수확률/최고·최저/미세먼지/초미세먼지
- **날씨 위치** — GPS 자동 또는 도시 검색 고정 (편집 모드에서 변경)
- **앱 타일 6칸** — 편집 모드에서 + 로 추가, × 로 삭제, 다른 앱으로 교체
- **위젯 좌/우 배치** — 편집 모드에서 전환
- **설정 저장** — 타일 구성·위젯 위치·날씨 위치가 앱을 꺼도 유지됨
- **음악 위젯** — UI만 있음 (실시간 연동은 2차 예정)

## 안드로이드 스튜디오에서 빌드하기

1. 안드로이드 스튜디오 실행 → File → Open → 이 `CarMode` 폴더 선택
2. Gradle 동기화가 자동으로 시작됨 (인터넷 필요, 처음엔 몇 분 걸림)
3. 폰을 USB로 연결 (USB 디버깅 켜둔 상태)
4. 상단 ▶ Run 버튼 → 폰 선택 → 설치 및 실행
5. 또는 Build → Build Bundle(s)/APK(s) → Build APK(s) 로 APK 파일 생성

## 홈 런처로 등록하는 법 (설치 후)

1. 앱이 설치되면 홈 버튼을 누름
2. "홈 앱 선택" 창이 뜸 → **차량 모드** 선택
3. "항상" 누르면 기본 런처로 고정
4. 되돌리려면: 설정 → 앱 → 기본 앱 → 홈 앱 → 삼성 원래 런처 선택

> 차에서만 쓰고 평소엔 삼성 런처를 쓰고 싶으면, "항상" 대신 "한 번만"을 누르거나,
> 설정에서 기본 홈 앱을 그때그때 바꾸는 방식을 권장.

## 권한

- **위치** — GPS 날씨용. 거부하면 서울 기본값으로 표시됨.
- **인터넷** — 날씨/대기질 조회용.

## 2차 예정

- 음악 실시간 연동 (재생 중인 곡 제목·앨범 표지·재생 제어)
  → 알림 접근 권한(NotificationListenerService) 필요
- 화면 항상 켜기, 밝기 조절 (주간/야간)
- 타일 순서 드래그 변경

## 참고

미세먼지는 Open-Meteo 글로벌 모델 기준이라 에어코리아(환경부) 수치와
약간 다를 수 있음. 한국 공식 수치가 필요하면 에어코리아 API로 교체 가능.
